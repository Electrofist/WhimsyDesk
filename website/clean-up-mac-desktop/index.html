How to clean up your Mac desktop without losing files

A cluttered desktop usually comes from three things: screenshots, downloads, and files you dropped there "for now". Here is how to clear it in a few minutes and keep it clear, using what is built into macOS. At the end there is a more playful option.

None of these steps delete anything. Your files only move.

1. Turn on Stacks

Stacks groups everything on your desktop into neat piles by kind: images, documents, PDFs, screenshots.

  1. Control-click an empty spot on the desktop.
  2. Choose Use Stacks.

Click a stack to open it, and click again to close it. To group by date instead, Control-click the desktop and choose Group Stacks By.

2. Send screenshots somewhere else

Screenshots are the biggest source of clutter, because macOS saves them to the desktop by default.

  1. Press Shift-Command-5.
  2. Click Options.
  3. Under Save to, choose a folder, for example a new folder called Screenshots in your Documents.

New screenshots go there from now on.

3. Check where downloads go

Most browsers save to the Downloads folder, but some are set to the desktop. In Safari, open Settings, then General, and check File download location. In Chrome, open Settings, then Downloads.

4. Tidy what is left

Control-click the desktop and choose Clean Up By, then Kind or Date Modified. Icons line up in a grid instead of piling on top of each other.

5. Hide desktop icons while you work

On macOS 14 Sonoma or later, open System Settings, then Desktop & Dock. Under Desktop & Stage Manager, turn off Show Items: On Desktop. Your files stay on the desktop and in Finder; they just stop showing on screen. Turn it back on any time.

A more playful way: objects that hold your files

If folders feel like a place where files go to be forgotten, WhimsyDesk is a set of free, open source Mac apps that give them somewhere nicer to live:

  • Desktop Fridge: drag files in and shut the heavy door. Files you leave too long frost over, as a gentle reminder.
  • Desktop Drawer: a wooden drawer that slides up from the bottom of the screen and holds everything you are not using right now.
  • Desktop Mailbox: a red post box that hides files behind its door, and receives a handpicked letter now and then.
  • Desktop Vending Machine: files stand on little shelves; press a button and one drops into the tray.

Files are moved into a normal folder you can open in Finder, never copied or deleted. Put Back returns any file to its exact spot on the desktop. They work on macOS 14 or later, with no accounts and no tracking.

Quick answers

Will cleaning up my desktop make my Mac faster? A little, if you have hundreds of large files there, because Finder draws a preview for each one. Mostly it makes things easier to find.

Is it safe to move files off the desktop? Yes. Moving a file to another folder doesn't change it. Apps that opened it before will ask where it went, and you can open it again from its new place.

Where do WhimsyDesk objects keep my files? In ordinary folders in your home folder, like ~/Fridge and ~/Desktop Drawer. See the FAQ for the full list.
