House rules

Gentle with your files, every time.

Every object in the library follows the same five rules. They are part of the guide, and each object is checked against them before it is added.

Read the rules
  1. 01

    Moved, never lost

    Files go into one plain folder you can open in Finder. Nothing is copied or deleted behind your back.

  2. 02

    Put Back works

    Every file can go back to where it came from, even after a restart.

  3. 03

    Quiet at rest

    No timers or animation while nobody is touching it. Easy on your battery.

  4. 04

    No network, no tracking

    No analytics, ads, accounts or paywalls. Ever.

  5. 05

    Free and open source

    MIT licence. Read it, change it, share it.

For makers

Make your own object.

Start from a template that already opens, closes, holds files and puts them back. Bring two pictures and the template does the rest. About 15 minutes, no Swift needed.

Read the guide Browse the template
Terminalsh
# Fork github.com/Electrofist/whimsydesk, then:
git clone https://github.com/your-username/whimsydesk.git
cd whimsydesk
scripts/new-object.sh "Toaster" your-username

Using Phoenix Code? Choose File, New Desktop Object instead. It does the same thing.

    Same size for both, transparent background, exported at 2x.

    Terminalsh
    cd objects/toaster
bash build.sh run

    The first build takes a minute or two. Your object appears at the lower left of your screen, behind your windows. Click it, drop a file on it, and right-click a file inside for Put Back.

    Terminalsh
    scripts/check-objects.sh
git checkout -b add-toaster
git add objects/toaster .github/CODEOWNERS
git commit -m "Add Toaster"
git push -u origin add-toaster

    Then open your fork on GitHub and choose Compare & pull request. GitHub checks and builds your object for you.

    Using Phoenix Code? Desktop Objects Studio shows your art, icon and card while you work, and marks mistakes in object.json as you type.
