## Use it

- Click to open or close it.
- Drag files or folders onto it. They move into `~/Desktop Objects/__FOLDER__`.
- Double-click an item to open it.
- Drag an item out onto the desktop or any folder to take it out.
- Right-click an item and choose Put Back to send it back where it came from.
- Hold Option and Command and drag to move the object. It remembers where you left it.
- Right-click for Open Folder, Put Everything Back and Quit.

## Build

```sh
./build.sh run
```

## Make it yours

- `Art/closed.png` and `Art/open.png`: your art. See `Art/README.md`.
- `Sounds/open.wav` and `Sounds/close.wav`: optional. See `Sounds/README.md`.
- `object.json`: name, description, and where files appear when open (`look.itemsArea`).
