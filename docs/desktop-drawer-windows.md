# Desktop Drawer for Windows

A wooden drawer for your Windows desktop that holds your files. Pull it out from the bottom of the screen, drop files in, push it shut. It is free, open source, and in beta for Windows 10 and 11.

[Download the installer](https://github.com/Electrofist/WhimsyDesk/releases/download/windows-drawer-beta.1/Desktop-Drawer-Setup.exe) (64-bit Windows 10 or 11).

## What it does

- **Weight.** Pull the front panel, or double-click it, to slide the drawer open. It has friction and soft bumpers, so it moves like a real drawer.
- **Files inside.** Drop files from the Desktop or File Explorer onto the open drawer. Drag them back out when you need them, or double-click a file to put it back where it came from.
- **Sound.** Wooden knocks and a sliding rumble that follows your hand.
- **Resize and move.** Alt-drag to resize the drawer, Ctrl+Alt-drag to move it.

Files are only ever moved, never copied or deleted. Nothing goes online, and there are no accounts.

## Where your files go

Into a normal folder called **Desktop Drawer**, next to your Desktop folder. If OneDrive syncs your Desktop, the folder sits inside OneDrive too, so moving files in never asks to delete them from the cloud.

Right-click the drawer and choose **Open Drawer Folder** to see them in File Explorer, or **Move Everything to Desktop** to empty it in one go.

## Install it

1. Download **Desktop-Drawer-Setup.exe**.
2. Open it. Windows may warn that the app is from an unknown publisher, because it is not signed yet. Click **More info**, then **Run anyway**.
3. The installer needs no admin rights. It adds Desktop Drawer to the Start menu and can start it with Windows.

The drawer sits along the bottom of your desktop, behind your windows. Press **Win+D** to see it.

Prefer no installer? There is also a [portable zip](https://github.com/Electrofist/WhimsyDesk/releases/tag/windows-drawer-beta.1): unzip it anywhere and run `DesktopDrawer.exe`.

## It is a beta
